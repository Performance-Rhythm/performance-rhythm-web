# PERFORMANCE RHYTHM WEBSITE ROADMAP

## Purpose

This roadmap translates the approved Performance Rhythm visual identity into concrete website implementation work.

The website should use the Performance Rhythm ECG / Performance Signal logo system, approved color palette, Montserrat typography, light backgrounds, premium simplicity, scientific credibility, human warmth, and calm high-performance styling.

---

# Visual Identity Implementation Priorities

## 1. Logo Asset Implementation

Implement the approved logo asset system across the website:

- Horizontal Logo in primary navigation
- Primary Logo in major brand moments where space allows
- Submark for compact placements, section details, and subtle brand moments
- Consistent clear-space and small-size treatment

## 2. Favicon System

Create and implement the approved Favicon System:

- 16x16 favicon
- 32x32 favicon
- SVG favicon
- Apple touch icon
- PWA / app manifest icons

Use the simplest possible version of the Performance Signal.

## 3. App Icon / PWA Asset System

If the website is installable as a PWA or saved to a device, create app icon assets using:

- Performance Signal as standalone mark
- Background `#FAFAF8`
- Signal in Primary `#0B1D2A` or Secondary `#5E8AA8`
- Accent `#D97742` only if legible and intentional
- Premium rounded-square container where appropriate

## 4. Social Preview System

Create Open Graph and social preview assets using the approved Social Media System:

- Open Graph default image
- LinkedIn preview image
- Article / content preview template
- Workshop / event preview template
- Founder-story preview template

## 5. Color Tokens

Implement approved website color tokens:

- Primary: `#0B1D2A`
- Secondary: `#5E8AA8`
- Accent: `#D97742`
- Support: `#A7BBC6`
- Neutral: `#ECE7DF`
- Background: `#FAFAF8`

Use Background `#FAFAF8` as the primary website surface.

Use Accent `#D97742` sparingly for calls to action, controlled highlights, and important interaction states.

## 6. Typography Tokens

Implement Montserrat typography:

- Montserrat Bold for headings, navigation emphasis, major statements, and CTA emphasis
- Montserrat Regular for body copy, navigation, labels, captions, and supporting content

## 7. Visual Motif System

Use subtle Performance Signal motifs for:

- Hero graphics
- Section dividers
- Methodology explanations
- Scroll transitions
- CTA moments
- Framework diagrams

Avoid literal medical ECG styling, endless pulsing, heartbeat monitor visuals, meditation/spiritual imagery, and generic wellness gradients.

---

# Acceptance Criteria

The website visual implementation should feel:

- Light
- Premium
- Modern
- Scientific
- Human
- High Performance
- Calm
- Credible

The website should not feel:

- Clinical
- Spiritual
- Generic wellness
- Fitness-app aggressive
- Dark-theme default
- Generic SaaS cluttered
