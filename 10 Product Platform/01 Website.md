# PERFORMANCE RHYTHM WEBSITE STRATEGY

## Purpose

The Performance Rhythm website exists to communicate our beliefs, establish credibility, generate conversations, and attract organizations aligned with our mission.

The website is not primarily a brochure.

The website is not primarily a wellness website.

The website is a leadership and performance platform designed to help organizations understand the connection between human capacity and organizational success.

The website should communicate one central idea:

Organizations achieve their greatest performance, growth, and impact when the people within them are able to thrive.

Professionally.

Personally.

Collectively.

# Website Visual Identity Direction

The website must use the approved Performance Rhythm visual identity system.

The website should feel:

- Light
- Premium
- Modern
- Scientific
- Human
- High Performance
- Calm
- Credible

The website should feel like Apple, Linear, Stripe, Notion, and Whoop combined with a human-centered performance brand — while remaining uniquely Performance Rhythm.

---

## Approved Logo System

Use the **Performance Rhythm ECG / Performance Signal** logo system.

Website applications should include:

- Horizontal Logo in the main navigation
- Primary Logo in major brand moments where space allows
- Submark for compact identity placements
- Favicon System for browser identity
- App Icon if the website is installed as a PWA or saved to a device
- Social Media System for Open Graph and social preview images

---

## Approved Color Palette

Primary: `#0B1D2A`  
Secondary: `#5E8AA8`  
Accent: `#D97742`  
Support: `#A7BBC6`  
Neutral: `#ECE7DF`  
Background: `#FAFAF8`

## Website Color Usage

Use Background `#FAFAF8` as the primary website surface.

Use Primary `#0B1D2A` for main text, navigation, wordmark, high-credibility sections, and premium anchor moments.

Use Secondary `#5E8AA8` for Performance Signal graphics, calm emphasis, supporting visuals, and selected UI accents.

Use Accent `#D97742` sparingly for calls to action, key moments of activation, controlled highlights, and small interaction states.

Use Support `#A7BBC6` for subtle dividers, quiet diagrams, secondary graphics, and supporting UI states.

Use Neutral `#ECE7DF` for warm panels, section backgrounds, proposal-style surfaces, and premium contrast areas.

---

## Typography

Use Montserrat.

- Montserrat Bold for headings, navigation emphasis, major statements, and CTA emphasis.
- Montserrat Regular for body copy, navigation, labels, captions, and supporting content.

Typography should feel modern, premium, readable, calm, scientific, human, and credible.
