# Performance Rhythm Brand System

## Brand Overview

### Mission

Performance Rhythm exists to help organizations create environments where people can perform, lead, grow, and thrive—professionally and personally—while driving exceptional organizational performance, growth, and impact.

We help leaders, teams, and organizations develop the human capacity that supports resilience, leadership effectiveness, emotional regulation, sustainable performance, and meaningful contribution.

Through nervous system regulation, human operating system development, leadership education, and practical performance training, we help organizations strengthen the people responsible for creating their success.

### Vision

We envision a future where organizations no longer view human wellbeing and organizational performance as competing priorities.

A future where leaders recognize that sustainable growth, innovation, resilience, customer experience, and long-term success are built upon healthy, capable, and thriving people.

A future where organizations become places that help people develop not only as employees, but as leaders, parents, spouses, teammates, friends, and human beings.

A future where organizations create meaningful value for customers while positively influencing employees, families, communities, and society.

Performance Rhythm seeks to help redefine workplace performance by making human capacity, leadership effectiveness, resilience, recovery, and nervous system health foundational elements of organizational success.

### Tagline

**Internal Balance. External Performance.**

### Core Promise

Performance Rhythm helps organizations strengthen the human capacity that drives resilience, leadership effectiveness, sustainable performance, growth, and long-term impact.

Healthy humans create healthier organizations.

Healthier organizations create greater performance, growth, and impact.

# Color System

## Approved Colors

### Primary

Deep Navy  
`#0B1D2A`

Use for wordmark, primary text, high-credibility applications, formal documents, premium anchor moments, dark linework, and monochrome logo applications.

### Secondary

Regulated Blue  
`#5E8AA8`

Use for the Performance Signal mark, calm visual emphasis, website graphics, supporting brand elements, product UI accents, and signal motifs.

### Accent

Performance Orange  
`#D97742`

Use sparingly for calls to action, moments of activation, signal highlights, key emphasis, progress or clarity moments, and small interaction states.

The accent should create controlled energy, not visual noise.

### Support

Soft Blue Gray  
`#A7BBC6`

Use for secondary graphics, charts, diagrams, UI support states, subtle dividers, and muted signal elements.

### Neutral

Warm Neutral  
`#ECE7DF`

Use for warm panels, subtle section backgrounds, presentation surfaces, soft contrast blocks, and premium off-white accents.

### Background

Soft White  
`#FAFAF8`

Use as the primary background for the website, sales decks, PDFs, product UI, social graphics, proposal documents, and brand collateral.

## Color Usage Guidelines

The palette should support light, premium, calm, credible brand expression.

Use the Primary color to create authority and depth.

Use the Secondary color to communicate regulation, stability, clarity, and healthy performance.

Use the Accent color sparingly to mark activation, clarity, progression, or calls to action.

Use Support, Neutral, and Background colors to create warmth, space, and quiet structure.

Avoid loud, overly energetic, mystical, spa-like, generic wellness, or clinical medical palettes.

# Logo System

## Approved Logo System

**Performance Rhythm ECG / Performance Signal**

The approved logo system uses a refined performance signal inspired by ECG rhythm, regulation, and sustainable human performance.

The mark should communicate:

- Internal Balance
- External Performance
- Regulation
- Rhythm
- Human Capacity
- Sustainable Performance
- Scientific Credibility
- Calm Confidence
- High Performance

The mark should feel like a premium performance signal, not a literal medical ECG, heartbeat monitor, wellness icon, meditation symbol, fitness tracker clone, or breathwork logo.

## Approved Logo Assets

The approved Performance Rhythm logo asset system includes:

1. Primary Logo
2. Horizontal Logo
3. Submark
4. App Icon
5. Favicon System
6. Social Media System

## Primary Logo

Use for formal brand applications, major website brand moments, sales deck covers, proposal covers, branded PDFs, workshop materials, and official company identity.

## Horizontal Logo

Use for website navigation, headers, email signatures, document footers, partner placements, and compact horizontal layouts.

## Submark

Use for compact brand placements, social avatars, slide corners, product UI, small-scale identity moments, and visual accents where the full wordmark is not needed.

## App Icon

Use for product, platform, mobile, desktop, PWA, and internal tool icons.

The app icon should use the Performance Signal as a standalone mark with generous negative space, a light background, and a premium rounded-square container where appropriate.

## Favicon System

Use the simplest possible version of the Performance Signal for browser tabs, bookmarks, website metadata, SVG favicon, Apple touch icon, and app manifest icons.

No wordmark should be used in the favicon.

## Social Media System

Use the Performance Signal, Primary Logo, Horizontal Logo, and Submark across LinkedIn company pages, founder profile graphics, social banners, post templates, newsletter graphics, content thumbnails, and Open Graph images.
